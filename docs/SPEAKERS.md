# All speaker IDs

The model has 723 speaker IDs. Three of them are the voices offered in the demos and the API (`studio`, `male`,
`female`). The others can be used with a numeric ID, e.g. `tts(text, speaker=17)` in Python. This page scores every ID
on the same test, so another voice can be picked by measurement. Rows are sorted by WER, then UTMOSv2; the raw numbers
are in [speakers.csv](speakers.csv).

**Protocol** (`scripts/eval_speakers.py`):
- **Text:** the first 50 sentences of [Freya-TR-Eval](https://huggingface.co/datasets/freyavoice/freya-tr-eval).
- **Settings:** T = 0.3, α = 2, seed = sentence index. IDs without their own duration factor use the global factor.
- **WER / CER:** Whisper large-v3 (beam 5) on audio downsampled to 8 kHz, as in the Freya protocol.
- **DNSMOS:** P.835 SIG / BAK / OVRL and P.808 on the full-band audio (resampled to 16 kHz), over all 50 sentences.
- **UTMOSv2, median F0:** on the first 10 sentences.
- **chars/s:** speaking rate, characters of the normalised text per second of audio.

With 50 sentences (about 400 words), one word error is 0.25% WER, so differences below about 1% between two IDs are
noise. All scores are automatic; none comes from listeners. Only the three named voices were selected for release,
so listen to any other ID before using it.

The three named voices were also scored on all 495 sentences: see [RESULTS.md](RESULTS.md#freya-tr-eval).
