Small deterministic fixtures generated by scripts/make_swift_fixtures.py.
They compare the native Swift implementation with the Python MLX implementation without network access.

These are randomly initialized, untrained test weights, not a usable speech checkpoint.
Generation uses MLX CPU with seed 123 and preserves float32 weights (no quantization).
The fixed 256-channel duration and pitch predictors make the safetensors set about 2.3 MB.
Duration projection is calibrated to 1.25 before ceil, yielding two frames/token at scale 1.
SnakeBeta alpha/beta and generator registers contain nonzero values.

model.safetensors / vocoder.safetensors: original Python parameter names and layouts.
config.json: complete three-speaker, 100-mel checkpoint with hop_length 8.
references.safetensors: direct model inputs/outputs, context crop and streamed waveform references.
cases.json: versioned case metadata and Python MLX version.

Coverage includes positive/negative pitch, changing token length, odd/even generator patches,
one-frame/short/long vocoder input, an interior context crop, Threefry RNG and a two-sentence
public streaming request with one silence interval. Fixture generation checks the Python
context crop against full decoding. Two independent generations match all 228 tensors exactly.

Regenerate from the repository root:
    python scripts/make_swift_fixtures.py

Run native checks with:
    swift run --package-path swift/DriftingTTS drifting-tts-swift --verify swift/DriftingTTS/Tests/DriftingTTSTests/Fixtures
